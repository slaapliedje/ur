Last time I said the Mega Drive and the Amiga were next in line. They didn't wait long: v0.1.6 adds native ports for both, which means the world's oldest board game now runs on fifteen machines — and the great 16-bit rivalry of the late 80s gets settled the old way, over a 4,600-year-old board.

Sega's turn: the Mega Drive / Genesis

The Genesis port is the Master System's showpiece look, done the way 16-bit hardware wants it done. The Genesis VDP gives you two independent tile planes, so the carved lapis board is drawn once on the back plane and the tokens live on the front plane with transparent corners — each disc literally rests on the stonework, with the carving visible around its rim. The moving piece glides as a hardware sprite, legal destinations tint green with their rosette or eye still showing, and the difficulty menu keeps its little gold rosette cursor.

My favourite detail: when Sega designed the Mega Drive, they kept the Master System's sound chip on board for the PSG — the same chip at the same clock. So the SMS port's sound code, and with it the 3,400-year-old Hurrian Hymn on the title screen, carried over byte for byte. I pointed a frequency analyser at the recording to be sure: F5, E5, D5, C5, B4 — the same descending line the Ugarit tablet has been holding onto since the Bronze Age, now in its third CPU family.

And the Amiga answers

The Amiga build is, fittingly, a port of the Atari ST version — the two great rivals running the same code, each showing off what it can. The Amiga picks its 16 colours from 4096 (the same palette space as the STe), so it gets the richer colour table: the deep-ember dusk behind the ziggurat, the warmer brick, the works. And it does it all politely: the port is OS-friendly and Kickstart 1.3-safe, opening a proper custom screen and driving Paula through audio.device — so it should behave on everything from a stock A500 to your accelerated 1200.

The download is a self-booting ADF — write it to a floppy or mount it and it boots straight into the ziggurat — plus the bare executable if you'd rather drop it on your hard drive.

Two war stories for the retro devs in the room. One: the classic Amiga GCC toolchain (bebbo's) quietly vanished from GitHub since I last looked — it lives on as the AmigaPorts project, which is what builds this port. Two: MAME's A500 driver greets you with a red screen declaring "THIS SYSTEM DOESN'T WORK." Press any key, and it proceeds to boot Kickstart 1.3 and run the game flawlessly for hours. Never trust a warning label.

One brain, fifteen machines

Every port on this page — Atari 8-bit to Falcon, Apple II, C64, the Coleco machines, Sega's three, Nintendo's three, and now the Amiga — runs the same portable C rules engine, byte for byte, across three CPU families: 6502, Z80, and 68000. The platform layers just draw. The whole thing is open source (GPLv3): github.com/slaapliedje/ur.

Bonus bug story: the linker that lied for two months

While shipping this release I finally chased down why the project's CI had been quietly red since July — every failure pointing at one build: the Apple II port's double-hi-res variant. The cause is a lovely piece of 8-bit archaeology. That build's memory map carved out its variable space between the end of the program and the C stack — and the program had grown past the boundary months ago, making that region mathematically negative in size. The old linker everyone has installed just… allowed it, silently letting variables overlap the stack's territory. The brand-new linker that CI compiles from source did the arithmetic honestly and refused. The machine wasn't broken; the map was, and only the newest tools could see it.

The fix is very Apple II: the double-hi-res screen uses page 2 of video memory, which leaves page 1 — a full 8 KB hole in the middle of the program — sitting empty. The variables now live inside the unused video page, under the graphics. Verified the honest way: booted it in an emulated enhanced IIe and played the computer with every variable relocated. Board fine, dice fine, green destination frames fine.

What's next

Polish for the new arrivals: the Genesis has a YM2612 FM synth sitting idle that deserves a proper lyre arrangement of the hymn, and the Amiga has a blitter and four Paula channels that could make this port sing in harmony — the machine that invented tracker music shouldn't settle for one square wave. And as always: if you run these on real hardware — a real A500, a real Genesis with a flashcart — I'd love to hear how they behave. That feedback has fixed more bugs than any emulator.
